# 🛡️ WG Panel — پنل مدیریت وایرگارد

پنل تحت وب فارسی برای ساخت و مدیریت کاربران **WireGuard** با حجم، انقضا، QR و اعمال خودکار.
آدرس پیش‌فرض پنل: **https://cloud.stackdome.com**

## امکانات
- ساخت کاربر با **کلید خصوصی/عمومی و PresharedKey خودکار** و تخصیص خودکار IP
- **انتخاب حجم (گیگابایت)** و **مدت اعتبار (روز)** برای هر کانفیگ، ساخت گروهی (تا ۱۰۰ کاربر)
- شمارش واقعی ترافیک (آپلود/دانلود) و **قطع خودکار** هنگام اتمام حجم یا پایان اعتبار
- فعال‌سازی خودکار با افزایش حجم/تمدید، ریست دستی حجم، **ریست ماهانهٔ خودکار** (اختیاری)
- دانلود فایل `.conf`، **QR Code**، و **لینک اشتراک عمومی** برای هر کاربر (صفحهٔ مصرف + کانفیگ)
- وضعیت آنلاین/آفلاین، آخرین اتصال
- تنظیم **آدرس پنل، Endpoint (IP/دامنه)، پورت، زیرشبکه، DNS، MTU، AllowedIPs، Keepalive** از داخل پنل
- تشخیص خودکار IP عمومی و کارت شبکهٔ خروجی (NAT)؛ IP forwarding و iptables خودکار
- پشتیبان‌گیری و بازیابی، گزارش رویدادها، تغییر نام کاربری/رمز مدیر
- امنیت: رمز با scrypt، کوکی HttpOnly/SameSite، محدودیت تلاش ناموفق ورود، هدرهای امنیتی
- بدون وابستگی سنگین: فقط Node.js (و ماژول اختیاری `qrcode` برای QR)

## نصب (Ubuntu 20.04+ / Debian 11+)
۱. رکورد **A** دامنه `cloud.stackdome.com` را به IP سرور بزنید (اگر Cloudflare دارید، حالت Proxy را **خاموش** کنید؛ وایرگارد UDP است).

۲. روی سرور:
```bash
git clone https://github.com/USERNAME/wg-panel.git
cd wg-panel
sudo DOMAIN=cloud.stackdome.com EMAIL=you@example.com bash install.sh
```
در پایان آدرس، نام کاربری و رمز نمایش داده می‌شود (همچنین در `/opt/wg-panel/data/initial-admin.txt`).

بدون دامنه/SSL (دسترسی مستقیم با IP):
```bash
sudo SKIP_NGINX=1 DOMAIN=SERVER_IP bash install.sh   # پنل روی http://SERVER_IP:3000
```

## استفاده
1. وارد پنل شوید ← **تنظیمات**: آدرس پنل و Endpoint را بررسی کنید (IP سرور به‌صورت خودکار پر می‌شود) ← ذخیره.
2. **کاربران ← کاربر جدید**: نام، حجم (GB) و اعتبار (روز) را بدهید.
3. QR را در اپ WireGuard اسکن کنید یا `.conf` / لینک اشتراک را بدهید.

## دستورات
```bash
systemctl status wg-panel        # وضعیت
journalctl -u wg-panel -f        # لاگ زنده
sudo bash update.sh              # به‌روزرسانی بعد از git pull
sudo bash uninstall.sh           # حذف (PURGE=1 برای حذف داده‌ها)
```

## متغیرهای محیطی (`/etc/wg-panel.env`)
| متغیر | توضیح |
|---|---|
| `PORT` / `HOST` | پورت و آدرس گوش‌دادن پنل (پیش‌فرض 3000 / 127.0.0.1 پشت nginx) |
| `PANEL_URL` | آدرس پنل برای اولین اجرا |
| `ENDPOINT` | آدرس سرور برای کانفیگ‌ها (خالی = تشخیص خودکار IP) |
| `DATA_DIR` | مسیر ذخیرهٔ دیتابیس (`db.json`) |
| `DRY_RUN=1` | اجرا بدون تغییر سیستم (برای توسعه/تست) |

## اجرای محلی برای تست
```bash
npm install
DRY_RUN=1 npm start     # http://localhost:3000
```

## نکات
- پورت UDP وایرگارد (پیش‌فرض 51820) باید در فایروال/پنل ارائه‌دهندهٔ سرور باز باشد.
- سرور باید دسترسی root و کرنل با پشتیبانی WireGuard داشته باشد (OpenVZ/LXC ممکن است پشتیبانی نکند).
- فایل پشتیبان شامل کلیدهای خصوصی است؛ امن نگه دارید.
